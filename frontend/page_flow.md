# โครงสร้างการเชื่อมโยงหน้าจอ (Page Navigation Flow)
เอกสารนี้อธิบายการเชื่อมโยง (User Flow) ระหว่างหน้าจอ (Views) ในระบบ IAMS รวมถึงกระบวนการทางราชการที่เสนอให้เพิ่มเข้ามา

---

## 1. การเข้าสู่ระบบ (Authentication)
* **`Login`** (หน้าล็อกอิน)
  * ล็อกอินสำเร็จ ➡️ ไปยังหน้า **`DashboardOverview`**
  * (หากมี) กดลืมรหัสผ่าน ➡️ ไปยังหน้า **Forget Password** (Modal หรือแยกหน้า)

## 2. หน้าหลัก (Dashboard)
* **`DashboardOverview`** (แดชบอร์ดสรุปภาพรวม)
  * กดเมนู "ทำเรื่องเบิกพัสดุ" ➡️ ไปยังหน้า **`NewRequisition`**
  * กดเมนู "รับเข้าพัสดุ" (สิทธิ์เจ้าหน้าที่) ➡️ ไปยังหน้า **`InventoryReceive`**
  * กดเมนู "ยืม-คืน" ➡️ ไปยังหน้า **`Borrow and Return`** (🆕 หน้าใหม่)
  * กดเมนู "แจ้งซ่อม" ➡️ ไปยังหน้า **`Maintenance and Repair`** (🆕 หน้าใหม่)
  * กดที่การแจ้งเตือน "งานรออนุมัติ" ➡️ ไปยังหน้า **`RequisitionManagement`**

## 3. ระบบคลังและรับเข้า (Inventory & Receiving)
* **`InventoryReceive`** (หน้ารับเข้าพัสดุ/ครุภัณฑ์)
  * เมื่อบันทึกรับเข้าสำเร็จ ➡️ ข้อมูลจะถูกส่งไปที่ **`InventoryStock`** (วัสดุ) หรือ **`AssetList`** (ครุภัณฑ์)
  * กด "ดูประวัติการรับเข้า" ➡️ ไปยังหน้า **`InventoryHistory`**
* **`InventoryStock`** (หน้าคลังวัสดุสิ้นเปลือง)
  * กดดูรายละเอียดวัสดุ ➡️ เปิดหน้าต่างย่อย (Modal / Drawer) แสดงยอดคงเหลือแต่ละ Lot
* **`AssetList`** (ทะเบียนครุภัณฑ์หลัก)
  * คลิกเลือกครุภัณฑ์ 1 รายการ ➡️ ไปยังหน้า **`AssetTimeline`** (เพื่อดูเส้นทางชีวิต/ประวัติของครุภัณฑ์ชิ้นนั้นๆ)

## 4. ระบบเบิก-จ่ายพัสดุ (Requisition Flow)
* **`NewRequisition`** (หน้าสร้างคำขอเบิกพัสดุ)
  * เลือกของเข้าตะกร้าและกดยืนยันคำขอ ➡️ ระบบพาไปที่หน้า **`RequisitionManagement`** เพื่อติดตามสถานะ
* **`RequisitionManagement`** (หน้าติดตามและจัดการคำขอเบิก)
  * **User:** กดดูคำขอตัวเอง ➡️ แสดงสถานะ (รออนุมัติ / ผ่าน / ถูกปฏิเสธ)
  * **Admin / ผู้อนุมัติ:** กดยืนยันการจ่ายของ ➡️ ไปยังหน้า **`AssetDistribution`**
* **`AssetDistribution`** (หน้าบันทึกการจ่ายของ)
  * ระบุจำนวนที่จ่ายจริงและกดยืนยัน ➡️ กลับไปยังหน้า **`RequisitionManagement`** พร้อมอัปเดตสถานะเป็น "จ่ายแล้ว"

## 5. 🆕 ระบบยืม-คืน (Borrow / Return Flow)
* **`Borrow and Return`** (หน้าจัดการยืม-คืนครุภัณฑ์)
  * กด "สร้างคำขอยืม" ➡️ เปิดหน้าต่างฟอร์มขอยืม
  * กด "คืนครุภัณฑ์" (สำหรับรายการที่ค้างอยู่) ➡️ เปิดฟอร์มบันทึกรับคืน พร้อมประเมินสภาพ (สมบูรณ์/ชำรุด)
  * หากตอนคืนพบว่า "ชำรุด" ➡️ สามารถคลิกส่งเรื่องต่อไปที่หน้า **`Maintenance and Repair`** ได้

## 6. 🆕 ระบบแจ้งซ่อม (Maintenance Flow)
* **`Maintenance and Repair`** (หน้าแจ้งซ่อมและประวัติ)
  * กด "แจ้งซ่อม" ➡️ เปิดฟอร์มเลือกครุภัณฑ์จาก AssetList ที่มีปัญหา
  * Admin ทำการประเมินราคาซ่อม ➡️ หากแพงเกินไป/ไม่คุ้ม ➡️ ส่งรายการนี้ไปยังหน้า **`Asset Disposal`** (ทำเรื่องแทงชำรุด)
  * อนุมัติซ่อมสำเร็จ ➡️ อัปเดตประวัติการซ่อมกลับไปที่หน้า **`AssetTimeline`**

## 7. 🆕 ระบบตรวจสอบประจำปี และ จำหน่ายครุภัณฑ์ (Annual & Disposal Flow)
* **`Annual Physical Inventory Check`** (หน้าตรวจสอบพัสดุประจำปี)
  * กรรมการเดินตรวจและอัปเดตสถานะ ➡️ หากพบรายการ "ชำรุด/เสื่อมสภาพ/สูญหาย" ➡️ กดปุ่มส่งรายการเหล่านี้ไปยังหน้า **`Asset Disposal`** รวดเดียว
* **`Asset Disposal and Write-off`** (หน้าจำหน่ายพัสดุ)
  * ดำเนินการอนุมัติการจำหน่าย (ขายทอดตลาด/ทำลาย ฯลฯ) ➡️ ระบบตัดครุภัณฑ์นี้ออกจาก **`AssetList`** อัตโนมัติ (เปลี่ยนสถานะเป็นจำหน่ายแล้ว)

## 8. ระบบรายงานและการตั้งค่า (Reporting & System Settings)
* **`ReportExport`** (หน้าออกรายงานและแบบฟอร์มราชการ)
  * เลือกเงื่อนไขรายงาน (สท.1, สท.2, บัญชีวัสดุ, สรุปรายปี) ➡️ กดปุ่ม Export (PDF/Excel)
* **`MasterData`** (หน้าจัดการข้อมูลหลัก / ทะเบียนฐานข้อมูล)
  * ตั้งค่าหมวดหมู่พัสดุ, เพิ่มชื่ออาคาร-สถานที่, ข้อมูลผู้จัดจำหน่าย
* **`Approval Workflow Settings`** (🆕 หน้าตั้งค่าสายการอนุมัติ)
  * กำหนดลำดับคนอนุมัติ (เช่น หัวหน้าฝ่าย -> ผอ.) ➡️ มีผลผูกพันไปบังคับใช้ในหน้า **Requisition**, **Borrow**, และ **Maintenance**
* **`UserProfile`** (หน้าโปรไฟล์ผู้ใช้)
  * ดูข้อมูลส่วนตัวและเปลี่ยนรหัสผ่าน
* **`ActivityLogs`** (หน้าบันทึกประวัติการใช้ระบบ)
  * Admin เข้ามาดูประวัติการคลิก การแก้ไขข้อมูลของแต่ละ User
