# คำอธิบายระบบ (System Description)
## ระบบบริหารจัดการพัสดุและครุภัณฑ์ (Asset and Inventory Management System)

### 1. ภาพรวมของระบบ (System Overview)
ระบบบริหารจัดการพัสดุและครุภัณฑ์ เป็นระบบสารสนเทศที่พัฒนาขึ้นเพื่ออำนวยความสะดวกในการจัดการข้อมูลพัสดุสิ้นเปลืองและครุภัณฑ์ภายในวิทยาลัย โดยครอบคลุมตั้งแต่การรับเข้า การเบิกจ่าย การย้ายสถานที่ติดตั้ง การติดตามตรวจสอบสถานะ ไปจนถึงการจัดทำบัญชีคุมและประวัติการใช้งานระบบอย่างเป็นระบบ

### 2. เทคโนโลยีที่ใช้ในการพัฒนา (Technology Stack)
- **Frontend Framework:** Vue 3 (Vite) ใช้เป็นโครงสร้างหลักในการพัฒนาเว็บแอปพลิเคชันแบบ Single Page Application (SPA)
- **CSS Framework:** Tailwind CSS สำหรับการจัดการสไตล์ เลย์เอาต์ และธีมสีอย่างรวดเร็วและเป็นระบบ
- **Iconography:** Lucide Vue Next ชุดไอคอนลายเส้นที่สะอาด ทันสมัย เหมาะกับระบบงานหลังบ้าน
- **Typography:** Google Fonts (Sarabun) ฟอนต์มาตรฐานภาษาไทยที่อ่านง่ายและมีความเป็นทางการ
- **Database:** Relational Database (ผ่านการ Normalized ระดับ 3NF) เพื่อความปลอดภัยและลดความซ้ำซ้อนของข้อมูล

### 3. โครงสร้างฐานข้อมูลและการจัดการข้อมูล (Database Architecture)
ฐานข้อมูลถูกแบ่งออกเป็น 8 ตารางหลัก เพื่อรองรับการจัดการข้อมูลอย่างครบถ้วน:
1. **Users (`users`):** จัดเก็บข้อมูลผู้ใช้งานและกำหนดสิทธิ์การใช้งานระบบ (Admin, Staff, User)
2. **Departments (`departments`):** จัดเก็บข้อมูลหน่วยงาน ฝ่าย หรืองาน ภายในวิทยาลัย
3. **Locations (`locations`):** จัดเก็บข้อมูลสถานที่ตั้ง อาคาร และห้องปฏิบัติการ
4. **Items (`items`):** ศูนย์กลางข้อมูลพัสดุและครุภัณฑ์หลัก เพื่อลดความซ้ำซ้อน (แสดงรหัส ชื่อ และจำนวนคงคลัง)
5. **Stock Transactions (`stock_transactions`):** บันทึกประวัติการรับเข้าและเบิกจ่าย (ตอบโจทย์บัญชีคุมพัสดุ)
6. **Assets (`assets`):** จัดเก็บข้อมูลครุภัณฑ์แบบรายชิ้น พร้อมสถานะปัจจุบัน (ใช้งาน, ส่งซ่อม, ชำรุด, จำหน่าย)
7. **Asset Distributions (`asset_distributions`):** บันทึกการจ่ายครุภัณฑ์ให้หน่วยงาน และประวัติการย้ายสถานที่
8. **Activity Logs (`activity_logs`):** ระบบ Audit Log สำหรับบันทึกความเคลื่อนไหวและตรวจสอบการทำธุรกรรมย้อนหลัง

### 4. การออกแบบส่วนติดต่อผู้ใช้งาน (UI/UX Design & Theme)
ระบบได้รับการออกแบบโดยเน้นความเรียบง่าย (Minimalist) โปร่งสบายตา และสอดคล้องกับอัตลักษณ์ของวิทยาลัย:
- **สีหลัก (Brand Colors):** เน้นโทนสี "เขียว-ขาว" โดยใช้สีเขียวหลัก (`#065f46`) สำหรับแถบเมนูและปุ่มสำคัญ ตัดกับพื้นหลังสีเทาอ่อน (`#f8fafc`) เพื่อลดความเมื่อยล้าทางสายตา
- **สีแสดงสถานะ (Status Colors):** 
  - 🟢 **สีเขียว:** สถานะปกติ / ใช้งาน / รับเข้า (Success)
  - 🟡 **สีเหลือง/ส้ม:** สถานะรอตรวจสอบ / ส่งซ่อม (Warning)
  - 🔴 **สีแดง:** สถานะชำรุด / แทงจำหน่าย / หมดสต๊อก (Danger)
  - 🔵 **สีน้ำเงิน:** สถานะเบิกจ่าย / กำลังเคลื่อนย้าย (Info)
- **การจัดวาง (Layout):** ประกอบด้วย Sidebar เมนูด้านข้างที่คงที่, Top Navbar ด้านบนสำหรับแสดงชื่อระบบ/โปรไฟล์, และพื้นที่คอนเทนต์หลักที่แสดงผลข้อมูลในรูปแบบ Card หรือตารางที่มีเส้นสายสะอาดตา

### 5. บทบาทและสิทธิ์ผู้ใช้งาน (Roles & Permissions)
- **แอดมิน (Admin):** สามารถจัดการข้อมูลผู้ใช้งาน ตั้งค่าระบบเชิงลึก และดูรายงานภาพรวมได้ทั้งหมด
- **เจ้าหน้าที่พัสดุ (Staff):** รับผิดชอบการเพิ่มข้อมูลครุภัณฑ์ จัดการการรับเข้า-เบิกจ่าย อัปเดตสถานะต่างๆ และตรวจสอบคลังสินค้า
- **ผู้ใช้งานทั่วไป (User):** สามารถดูข้อมูลครุภัณฑ์ที่อยู่ในความรับผิดชอบ ทำเรื่องขอเบิกพัสดุ และตรวจสอบสถานะคำขอของตนเอง
