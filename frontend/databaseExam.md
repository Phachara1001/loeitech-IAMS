# รายละเอียดโครงสร้างฐานข้อมูล (Database Schema & Data Dictionary)

ระบบบริหารจัดการพัสดุและครุภัณฑ์ (Asset and Inventory Management System) ประกอบไปด้วยตารางทั้งหมด 8 ตารางที่ผ่านการ Normalized (3NF) เรียบร้อยแล้ว ดังนี้:

---

## 1. ตารางข้อมูลผู้ใช้งาน (`users`)

**คำอธิบาย:** เก็บข้อมูลบัญชีผู้ใช้งานระบบและระดับสิทธิ์การเข้าถึงข้อมูลตามบทบาทหน้าที่[cite: 1, 2]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type)       | Key | Constraints               | คำอธิบาย                                                                |
| :--------------------- | :--------------------------- | :-: | :------------------------ | :---------------------------------------------------------------------- |
| `user_id`              | INT                          | PK  | Auto Increment            | รหัสผู้ใช้งานหลัก                                                       |
| `username`             | VARCHAR(50)                  |  -  | Unique, NOT NULL          | ชื่อบัญชีสำหรับการ Login เข้าสู่ระบบ                                    |
| `password_hash`        | VARCHAR(255)                 |  -  | NOT NULL                  | รหัสผ่านที่ผ่านการเข้ารหัส (Hashing)                                    |
| `full_name`            | VARCHAR(100)                 |  -  | NOT NULL                  | ชื่อ-นามสกุลจริงของผู้ใช้งาน[cite: 1]                                   |
| `role`                 | ENUM('Admin','Staff','User') |  -  | NOT NULL                  | สิทธิ์การเข้าใช้งานระบบ (แอดมิน/เจ้าหน้าที่พัสดุ/ผู้ใช้ทั่วไป)[cite: 1] |
| `created_at`           | TIMESTAMP                    |  -  | DEFAULT CURRENT_TIMESTAMP | วันและเวลาที่สร้างบัญชีผู้ใช้งาน                                        |

---

## 2. ตารางหน่วยงาน/ฝ่าย (`departments`)

**คำอธิบาย:** เก็บรายชื่อฝ่าย งาน หรือสาขาวิชาภายในวิทยาลัย เพื่อรองรับข้อมูลช่อง "นามหน่วย" หรือ "ฝ่ายที่เบิก"[cite: 1]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type) | Key | Constraints      | คำอธิบาย                                                |
| :--------------------- | :--------------------- | :-: | :--------------- | :------------------------------------------------------ |
| `dept_id`              | INT                    | PK  | Auto Increment   | รหัสหน่วยงานภายในระบบ                                   |
| `dept_name`            | VARCHAR(100)           |  -  | Unique, NOT NULL | ชื่อหน่วยงานหรือฝ่าย (เช่น ฝ่ายบริหารทรัพยากร)[cite: 1] |

---

## 3. ตารางสถานที่ติดตั้ง (`locations`)

**คำอธิบาย:** เก็บข้อมูลอาคาร ห้องเรียน หรือห้องปฏิบัติการ เพื่อระบุพิกัดที่อยู่ของครุภัณฑ์รายชิ้น[cite: 1]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type) | Key | Constraints    | คำอธิบาย                                 |
| :--------------------- | :--------------------- | :-: | :------------- | :--------------------------------------- |
| `location_id`          | INT                    | PK  | Auto Increment | รหัสสถานที่ภายในระบบ                     |
| `building_name`        | VARCHAR(100)           |  -  | NOT NULL       | ชื่ออาคารเรียนหรืออาคารสำนักงาน[cite: 1] |
| `room_name`            | VARCHAR(100)           |  -  | NOT NULL       | ชื่อห้อง หรือหมายเลขห้องเรียน[cite: 1]   |

---

## 4. ตารางพัสดุและครุภัณฑ์หลัก (`items`)

**คำอธิบาย:** (ตารางศูนย์กลางข้อมูลพัสดุ) เก็บคุณลักษณะร่วมพื้นฐานของพัสดุสิ้นเปลืองและครุภัณฑ์หลัก เพื่อลดความซ้ำซ้อนของข้อมูล (รองรับแบบ พ.3102-8)[cite: 1]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type)    | Key | Constraints      | คำอธิบาย                                                                |
| :--------------------- | :------------------------ | :-: | :--------------- | :---------------------------------------------------------------------- |
| `item_id`              | INT                       | PK  | Auto Increment   | รหัสพัสดุภายในระบบ                                                      |
| `item_code`            | VARCHAR(50)               |  -  | Unique, NOT NULL | **หมายเลขพัสดุหลัก** (เช่น `2310-004-0002`)[cite: 1]                    |
| `item_name`            | VARCHAR(150)              |  -  | NOT NULL         | **ชื่อพัสดุ** (เช่น รถยนต์โดยสารตู้ 15 ที่นั่ง (เบนซิน))[cite: 1]       |
| `item_type`            | ENUM('Inventory','Asset') |  -  | NOT NULL         | **ประเภท** (`Inventory` = พัสดุสิ้นเปลือง, `Asset` = ครุภัณฑ์)[cite: 1] |
| `unit_name`            | VARCHAR(30)               |  -  | NOT NULL         | **หน่วยนับ** (เช่น คัน, ชิ้น, แพ็ค, ตัว)[cite: 1]                       |
| `description`          | TEXT                      |  -  | Nullable         | **รายละเอียดคุณลักษณะ** (เช่น จำนวน 4 สูบ 1998 ซีซี)[cite: 1]           |
| `min_qty`              | INT                       |  -  | DEFAULT 0        | **อัตราความต้องการขั้นต้น** (ใช้คุมสต๊อกขั้นต่ำ)[cite: 1]               |
| `current_stock`        | INT                       |  -  | DEFAULT 0        | **จำนวนคงคลังปัจจุบัน** ที่พร้อมใช้งานในสต๊อกหลัก[cite: 1]              |

---

## 5. ตารางธุรกรรมคลังสินค้า (`stock_transactions`)

**คำอธิบาย:** บันทึกประวัติการรับเข้าและเบิกจ่ายพัสดุทั้งหมด **(ตอบโจทย์ บัญชีคุมพัสดุ หน้า 1 และ หน้า 2)**[cite: 1]

| ชื่อฟิลด์ (Field Name)  | ชนิดข้อมูล (Data Type)  | Key | Constraints                   | คำอธิบาย                                                                      |
| :---------------------- | :---------------------- | :-: | :---------------------------- | :---------------------------------------------------------------------------- |
| `transaction_id`        | INT                     | PK  | Auto Increment                | รหัสธุรกรรมคลังสินค้า                                                         |
| `item_id`               | INT                     | FK  | REFERENCES `items`(`item_id`) | รหัสพัสดุหลักที่เกิดการเคลื่อนไหว[cite: 1]                                    |
| `transaction_date`      | DATE                    |  -  | NOT NULL                      | **ว.ด.ป.** ที่ทำรายการจริงตามเอกสาร[cite: 1]                                  |
| `fiscal_year`           | YEAR                    |  -  | NOT NULL                      | **ปีงบประมาณ** (เช่น 2556)[cite: 1]                                           |
| `transaction_type`      | ENUM('Receive','Issue') |  -  | NOT NULL                      | **ประเภทธุรกรรม** (`Receive` = รับเข้า, `Issue` = เบิกจ่าย)[cite: 1]          |
| `document_ref`          | VARCHAR(100)            |  -  | NOT NULL                      | **หลักฐานอ้างอิง** (เลขที่ใบส่งของ หรือ เลขที่ใบเบิก เช่น `7039-56`)[cite: 1] |
| `source_or_destination` | VARCHAR(150)            |  -  | NOT NULL                      | บริษัทที่ส่งของ หรือ หน่วยงานที่รับของไป (เช่น โตโยต้า จำกัด)[cite: 1]        |
| `acquisition_method`    | VARCHAR(50)             |  -  | Nullable                      | **วิธีการได้มา** (เช่น สอบราคา) _[ระบุเฉพาะตอนรับเข้า]_[cite: 1]              |
| `funding_type`          | VARCHAR(50)             |  -  | Nullable                      | **ประเภทเงิน** (เช่น งบประมาณ) _[ระบุเฉพาะตอนรับเข้า]_[cite: 1]               |
| `unit_price`            | DECIMAL(10,2)           |  -  | NOT NULL, DEFAULT 0.00        | **ราคาต่อหน่วย** ของพัสดุในล็อตนั้น[cite: 1]                                  |
| `quantity`              | INT                     |  -  | NOT NULL                      | **จำนวน** ที่นำเข้าหรือเบิกออก[cite: 1]                                       |
| `balance_qty`           | INT                     |  -  | NOT NULL                      | **จำนวนคงคลัง** สรุปยอดสะสม ณ จบธุรกรรมนั้น[cite: 1]                          |
| `created_by`            | INT                     | FK  | REFERENCES `users`(`user_id`) | รหัสผู้บันทึกรายการ (ช่อง **"ลายมือชื่อ"** อ้างอิงตารางผู้ใช้)[cite: 1]       |

---

## 6. ตารางครุภัณฑ์รายชิ้น (`assets`)

**คำอธิบาย:** เก็บข้อมูลหมายเลขประจำชิ้นของครุภัณฑ์ย่อยแบบ 1 ต่อ 1 **(ตอบโจทย์ บัญชีคุมเลขลำดับครุภัณฑ์ หน้า 3)**[cite: 1]

| ชื่อฟิลด์ (Field Name)   | ชนิดข้อมูล (Data Type)                        | Key | Constraints                     | คำอธิบาย                                                               |
| :----------------------- | :-------------------------------------------- | :-: | :------------------------------ | :--------------------------------------------------------------------- |
| `asset_id`               | INT                                           | PK  | Auto Increment                  | รหัสครุภัณฑ์รายชิ้นภายในระบบ                                           |
| `item_id`                | INT                                           | FK  | REFERENCES `items`(`item_id`)   | รหัสพัสดุหลักเพื่อผูกโยงชื่อและคุณลักษณะ[cite: 1]                      |
| `asset_number`           | VARCHAR(50)                                   |  -  | Unique, NOT NULL                | **เลขลำดับครุภัณฑ์** ย่อยประจำชิ้น (เช่น `561-001`)[cite: 1]           |
| `serial_number`          | VARCHAR(100)                                  |  -  | Nullable                        | **เลขทะเบียน**/Serial Number โรงงาน (เช่น ทะเบียนรถ `- 9146`)[cite: 1] |
| `status`                 | ENUM('Active','Repaired','Broken','Scrapped') |  -  | DEFAULT 'Active'                | **สถานะครุภัณฑ์** (ใช้งานปกติ, ส่งซ่อม, ชำรุด, แทงจำหน่าย)[cite: 1]    |
| `receive_transaction_id` | INT                                           | FK  | REFERENCES `stock_transactions` | ผูกกับล็อตใบรับเข้าคลังเพื่อดึงข้อมูลราคาและวันตรวจรับ[cite: 1]        |

---

## 7. ตารางการจ่ายครุภัณฑ์ให้หน่วยงาน (`asset_distributions`)

**คำอธิบาย:** บันทึกการกระจายครุภัณฑ์ย่อยให้แต่ละหน่วยงานและประวัติการย้ายสถานที่ **(ตอบโจทย์ บัญชีคุมครุภัณฑ์จ่ายให้หน่วย หน้า 4)**[cite: 1]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type) | Key | Constraints                           | คำอธิบาย                                                                          |
| :--------------------- | :--------------------- | :-: | :------------------------------------ | :-------------------------------------------------------------------------------- |
| `distribution_id`      | INT                    | PK  | Auto Increment                        | รหัสการจ่ายครุภัณฑ์                                                               |
| `asset_id`             | INT                    | FK  | REFERENCES `assets`(`asset_id`)       | รหัสครุภัณฑ์ชิ้นย่อยที่ถูกกระจายออกไป[cite: 1]                                    |
| `dept_id`              | INT                    | FK  | REFERENCES `departments`(`dept_id`)   | **นามหน่วย/ฝ่าย** ที่นำครุภัณฑ์ไปใช้งาน (เช่น ฝ่ายบริหารฯ)[cite: 1]               |
| `location_id`          | INT                    | FK  | REFERENCES `locations`(`location_id`) | **สถานที่ติดตั้ง** (อาคาร/ห้องเรียนที่ครุภัณฑ์ตั้งอยู่)[cite: 1]                  |
| `responsible_user_id`  | INT                    | FK  | REFERENCES `users`(`user_id`)         | **ผู้รับผิดชอบหลัก** หรือผู้ครอบครองครองครุภัณฑ์ชิ้นนี้[cite: 1]                  |
| `issue_document_ref`   | VARCHAR(100)           |  -  | NOT NULL                              | **หลักฐานจ่าย** (เลขที่ใบเบิกที่ได้รับชิ้นนี้ไป เช่น `7039-56`)[cite: 1]          |
| `assigned_date`        | DATE                   |  -  | NOT NULL                              | วันที่ส่งมอบครุภัณฑ์ให้หน่วยงานเริ่มใช้งาน[cite: 1]                               |
| `return_date`          | DATE                   |  -  | Nullable                              | วันที่ส่งคืนหรือย้ายออก (บันทึกค่าเมื่อครุภัณฑ์พ้นสภาพจากหน่วยนี้)[cite: 1]       |
| `is_current`           | BOOLEAN                |  -  | NOT NULL, DEFAULT 1                   | สถานะหน่วยปัจจุบัน (`1` = กำลังใช้งานอยู่, `0` = ย้ายไปแล้ว/เป็นประวัติ)[cite: 1] |

---

## 8. ตารางประวัติการใช้งานระบบ (`activity_logs`)

**คำอธิบาย:** ทำหน้าที่เป็น Audit Log บันทึกกิจกรรมบนเว็บไซต์ทั้งหมดเพื่อความปลอดภัยและการตรวจสอบย้อนหลัง[cite: 1, 2]

| ชื่อฟิลด์ (Field Name) | ชนิดข้อมูล (Data Type)                   | Key | Constraints                   | คำอธิบาย                                                               |
| :--------------------- | :--------------------------------------- | :-: | :---------------------------- | :--------------------------------------------------------------------- |
| `log_id`               | INT                                      | PK  | Auto Increment                | รหัส Log                                                               |
| `user_id`              | INT                                      | FK  | REFERENCES `users`(`user_id`) | รหัสผู้ใช้งานที่เป็นคนทำรายการบนเว็บไซต์[cite: 1]                      |
| `action_type`          | ENUM('INSERT','UPDATE','DELETE','LOGIN') |  -  | NOT NULL                      | ประเภทพฤติกรรม (เพิ่มข้อมูล, แก้ไขข้อมูล, ลบข้อมูล, เข้าระบบ)[cite: 1] |
| `table_name`           | VARCHAR(50)                              |  -  | NOT NULL                      | ชื่อตารางในฐานข้อมูลที่ได้รับผลกระทบ (เช่น `assets`)[cite: 1]          |
| `record_id`            | INT                                      |  -  | NOT NULL                      | ID ของแถวข้อมูลในตารางนั้นๆ ที่ถูกกระทำ                                |
| `old_value`            | TEXT                                     |  -  | Nullable                      | ข้อมูลเดิมก่อนการแก้ไข (เก็บเป็นรูปแบบ JSON String)                    |
| `new_value`            | TEXT                                     |  -  | Nullable                      | ข้อมูลใหม่หลังแก้ไข หรือข้อมูลที่เพิ่งเพิ่มเข้าไป (รูปแบบ JSON String) |
| `ip_address`           | VARCHAR(45)                              |  -  | NOT NULL                      | หมายเลข IP Address ของเครื่องคอมพิวเตอร์ผู้ใช้งาน                      |
| `created_at`           | TIMESTAMP                                |  -  | DEFAULT CURRENT_TIMESTAMP     | วันและเวลาที่เกิดกิจกรรมนี้ขึ้นจริงในระบบ (บันทึกอัตโนมัติ)            |
