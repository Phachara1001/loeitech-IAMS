# คู่มือระบบการออกแบบและสไตล์หน้าเว็บ (UI Design System & Style Guide)

เอกสารฉบับนี้จัดทำขึ้นเพื่อกำหนดมาตรฐานการออกแบบหน้าจอผู้ใช้งาน (User Interface) ของระบบบริหารจัดการพัสดุและครุภัณฑ์ โดยอิงตามอัตลักษณ์ธีมสีหลักเขียว-ขาวของวิทยาลัย ผสมผสานสไตล์มินิมอลที่เน้นความโปร่งและอ่านง่าย[cite: 1, 2]

---

## 1. เครื่องมือตกแต่งและพัฒนาหน้าเว็บ (Frontend UI Stack)

- **Vue 3 (Vite):** โครงสร้างหลักในการพัฒนาคอมโพเนนต์หน้าเว็บ
- **Tailwind CSS:** ยูทิลิตี้ CSS เฟรมเวิร์กหลักสำหรับจัดแต่งหน้าจอ เลย์เอาต์ และระบบสีอย่างรวดเร็ว
- **Lucide Vue Next (`lucide-vue-next`):** ชุดไอคอนแบบลายเส้น (Vector Icons) ที่สะอาด ทันสมัย เหมาะกับเว็บระบบสารสนเทศหลังบ้าน
- **Google Fonts (Sarabun):** ฟอนต์มาตรฐานภาษาไทยที่เป็นทางการ อ่านง่าย เหมาะสมกับระบบงานพัสดุราชการ

---

## 2. ระบบฟอนต์และการจัดวางอักษร (Typography)

ระบบจะบังคับใช้ฟอนต์ **"Sarabun"** จาก Google Fonts เป็นหลักทั่วทั้งเว็บไซต์ผ่าน Tailwind CSS configuration (`font-sans`)[cite: 1] เพื่อความเป็นระเบียบและอ่านง่าย[cite: 2]

- **Font Family:** `Sarabun`, `sans-serif`
- **ขนาดอักษรและน้ำหนัก (Hierarchy):**
  - **หัวข้อหลักของหน้า (Page Title):** `text-2xl` หรือ `text-3xl` | Weight: `font-bold` (`700`)
  - **หัวข้อการ์ด / หัวตาราง (Card/Table Header):** `text-lg` หรือ `text-base` | Weight: `font-semibold` (`600`)
  - **เนื้อหาทั่วไป / ข้อมูลในตาราง (Body Text):** `text-sm` หรือ `text-base` | Weight: `font-normal` (`400`)
  - **คำอธิบายย่อย / ป้ายกำกับ (Small/Badge Text):** `text-xs` | Weight: `font-medium` (`500`)

## 3. ระบบธีมสีหน้าเว็บ (Hex Color Palette)

เพื่อควบคุมบรรยากาศโดยรวมให้เป็น "เขียว-ขาว" ประจำวิทยาลัย แต่ยังคงความชัดเจนในการแยกแยะข้อมูล จึงแบ่งกลุ่มโทนสีตามสถานการณ์การใช้งานบน UI ดังนี้:[cite: 1]

### 3.1 สีหลักประจำวิทยาลัยและโครงสร้างเว็บ (Brand & Base Colors)

- **สีเขียวหลัก (Primary Green):** `#065f46`
  - _การใช้งาน:_ แถบเมนูด้านข้าง (Sidebar), หัวแถบบน (Navbar), ปุ่มบันทึกข้อมูลหลัก[cite: 1]
- **สีเขียวสำหรับ Hover (Primary Hover):** `#047857`
  - _การใช้งาน:_ แสดงผลเมื่อนำเมาส์ไปชี้ที่ปุ่มหรือเมนูหลัก
- **สีพื้นหลังหน้าเว็บ (Background Light):** `#f8fafc`
  - _การใช้งาน:_ พื้นหลังรวมของหน้าจอ ช่วยลดความเมื่อยล้าสายตาเวลาทำงานนาน ๆ
- **สีพื้นหลังบล็อกข้อมูล (Card White):** `#ffffff`
  - _การใช้งาน:_ พื้นหลังของการ์ดสรุปผล แผ่นตารางข้อมูล และกล่องกรอกฟอร์ม
- **สีตัวอักษรเนื้อหาหลัก (Text Primary):** `#0f172a`
  - _การใช้งาน:_ ใช้กับเนื้อหาข้อความทั่วไปและตัวเลขสำคัญ

### 3.2 สีแสดงสถานะข้อมูลและสถานการณ์ (Status & Contextual Colors)

ออกแบบมาให้ใช้เป็นคู่สี **"ตัวอักษรเข้ม + พื้นหลังอ่อน"** สำหรับทำป้ายกำกับ (Badge/Tag) ในตาราง:[cite: 1]

- **🟢 สถานะปกติ / สำเร็จ / การรับเข้าพัสดุ (Success & Active)**
  - สีตัวอักษร: `#047857` | สีพื้นหลังป้าย: `#ecfdf5`
  - _การใช้งาน:_ ครุภัณฑ์สถานะ "ใช้งานปกติ", ธุรกรรม "รับเข้าคลัง", คำขอเบิกที่ "อนุมัติแล้ว"[cite: 1, 2]
- **🟡 สถานะรอตรวจสอบ / อยู่ระหว่างซ่อม (Warning & Maintenance)**
  - สีตัวอักษร: `#b45309` | สีพื้นหลังป้าย: `#fffbeb`
  - _การใช้งาน:_ ครุภัณฑ์สถานะ "ส่งซ่อม", คำขอเบิกที่ "รออนุมัติ", แจ้งเตือน "พัสดุใกล้หมด"[cite: 1, 2]
- **🔴 สถานะชำรุด / จำหน่ายออก / สินค้าหมด (Danger & Alert)**
  - สีตัวอักษร: `#be123c` | สีพื้นหลังป้าย: `#fff1f2`
  - _การใช้งาน:_ ครุภัณฑ์สถานะ "ชำรุด", "แทงจำหน่าย", พัสดุสิ้นเปลือง "หมดสต๊อก", Log การลบข้อมูล[cite: 1, 2]
- **🔵 สถานะการเบิกจ่าย / กำลังเคลื่อนย้าย (Info & Issue)**
  - สีตัวอักษร: `#1d4ed8` | สีพื้นหลังป้าย: `#eff6ff`
  - _การใช้งาน:_ ธุรกรรม "เบิกจ่ายพัสดุ", ครุภัณฑ์ที่อยู่ระหว่าง "กำลังย้ายสถานที่ติดตั้ง"[cite: 1, 2]

## 4. โครงสร้างและส่วนประกอบหน้าเว็บ (Layout & UI Components)

### 4.1 เลย์เอาต์หลัก (Main Layout)

- **Sidebar Navigation:** แถบซ้ายมือสีเขียวเข้ม (`#065f46`) คงที่ตลอดเวลา เมนูประกอบด้วยไอคอน Lucide[cite: 1] คู่กับข้อความฟอนต์ Sarabun สีขาว
- **Top Navbar:** แถบบนสีขาวล้วน แยกข้อมูลฝั่งซ้ายเป็นชื่อระบบและปีงบประมาณปัจจุบัน ฝั่งขวาเป็นโปรไฟล์ผู้ใช้งานและปุ่มแจ้งเตือน
- **Main Content Window:** พื้นหลังสีเทาอ่อนสว่าง (`#f8fafc`) เนื้อหาภายในจะบรรจุลงในการ์ดสีขาวโค้งมนเล็กน้อย (`rounded-lg`) พร้อมเงาจาง ๆ (`shadow-sm`)

### 4.2 ตารางข้อมูล (Data Table Component)

- **Header:** แถวหัวตารางใช้พื้นหลังสีเทาอ่อน ตัวอักษรหนา กึ่งกลางหรือชิดซ้ายตามความเหมาะสม
- **Rows:** แถวข้อมูลในตารางใช้เอฟเฟกต์เปลี่ยนสีเมื่อเมาส์ชี้ผ่าน (`hover:bg-slate-50`) เพื่อให้อ่านข้อมูลเป็นบรรทัดยาวได้ง่าย ไม่สับสนช่อง
- **Pagination & Action Buttons:** ปุ่มเปลี่ยนหน้าและปุ่ม Action (แก้ไข/ดูรายละเอียด) ใช้ขอบโค้งมน ไอคอน Lucide ชัดเจน ระยะห่างปุ่มพอดีกับการกดใช้งานผ่านเบราว์เซอร์
